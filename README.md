# Portfolio
Projects that i have participated throughout my school career


📚 Academic Projects

 🔐 SecureSys — A Data Security System for Clinics

SecureSys is an academic project developed to improve the protection of clinic-related information. It focuses on securing stored data, controlling user access, and supporting safer management of patient and treatment records within a straightforward and organized digital environment.

 👕 Viveres Clothing Store

Viveres Clothing Store is a web-based shopping platform created to showcase clothing products digitally. It features an organized product catalog where customers can discover different items, check essential product information, and navigate the store through a convenient and visually engaging interface.

 📅 Arcana — Student Organizer

Arcana is an academic productivity application created to assist students with their daily school responsibilities. It brings important academic activities into one organized platform, helping users monitor upcoming requirements, arrange their schedules, and maintain better awareness of their school commitments.
